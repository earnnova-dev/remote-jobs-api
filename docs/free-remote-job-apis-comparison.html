What we learned from running them

No single source is "the" feed

The biggest source returned ~10× more listings than the smallest. No one endpoint covers the market — which is exactly why aggregators exist.

Formats don't match

JSON, RSS/XML, and raw HTML all in one niche. If you consume two or three, you're writing a parser for each — and each one breaks when the board changes its markup.

Salary is the differentiator

Only one of the six gave you real salary ranges for free. That single field is often the most valuable for filtering and ranking — and it's the hardest to get consistently.

Two practical traps we hit directly: RemoteOK silently caps you at 100 listings without a token, and RemoteLeaf is HTML, not an API — so "174 jobs" is a scrape, not a stable schema. Both look like solid feeds until you build on them.

One endpoint instead of six parsers

If you need structured remote-job data from several of these at once, Remote Jobs API pulls Remotive, RemoteOK, Jobicy, We Work Remotely and Hacker News, normalizes every listing into a single schema, dedupes it, and returns JSON or CSV — with an optional 0–100 skill fit-score. Self-hostable, stdlib-only Python, no key required to try.
