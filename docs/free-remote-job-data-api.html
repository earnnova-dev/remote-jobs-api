Free Remote Job Data API (2026)

One endpoint that returns structured remote-job data from 5 boards in a single schema — JSON or CSV — with an optional 0–100 skill fit score. Self-host it free (MIT, Python stdlib-only) or call the hosted version.

Building a job feed, a recruiter tool, a lead-gen model, or an AI agent that needs live remote-job data usually means writing and maintaining five separate scrapers — one per board, each with its own quirks and breakage. A remote-job data API removes that: a single GET /v1/jobs returns every board normalized into one schema, deduplicated, with a reproducible skill fit score so you can rank without a hidden LLM.

What you get: a GET endpoint returning count + a jobs array of normalized objects (title, company, url, location, category, source, published, and optional fit_score). Boards covered: Remotive, RemoteOK, We Work Remotely, Jobicy, and Hacker News "Who is Hiring". All self-hostable and free — the same engine also runs as a hosted, high-rate-limit service.

What a job data API gives you

One schema across every board

Remotive is JSON, We Work Remotely is RSS, RemoteOK is HTML-backed JSON. You never write per-board adapters — the API normalizes all five into identical fields.

Structured, not scraped-on-demand

Reads the boards' public no-auth endpoints and returns clean JSON/CSV. No browser, no account, no session scraping — so no CAPTCHAs and no rate-limit roulette on your side.

A deterministic fit score

Pass skills=python,backend,api and each job gets a reproducible fit_score (0–100), ranked best-first. No black-box LLM — the ranking is unit-testable and stable.

Self-hostable, zero dependencies

Pure Python stdlib. Run it on a laptop, a $5 VPS, or the included Dockerfile. MIT-licensed, free to self-host.

The endpoint

MethodPathDescription
GET/healthStatus + live job count
GET/v1/jobs/sourcesAvailable boards
GET/v1/jobsNormalized job listings

Query params on /v1/jobs:

ParamTypeNotes
skillsstringComma-separated keywords → adds fit_score, ranks best-first
sourcestringremotive / remoteok / jobicy / wwr / hn
limitint1–500 (default 50)
min_scoreint0–100, filter by fit (needs skills)
formatstringjson (default) or csv
curl "https://<your-host>/v1/jobs?skills=python,backend,api&limit=3"

Use it right now (free)

Option A — CLI, no server needed: query the feed directly.

pip install remote-jobs-api
remote-jobs-api --skills python,api --limit 5
remote-jobs-api --source wwr --format csv

Option B — run your own API server:

pip install remote-jobs-api
remote-jobs-api --serve --port 8321     # or: python -m remote_jobs_api.server

Or from source / Docker:

git clone https://github.com/earnnova-dev/remote-jobs-api
cd remote-jobs-api
python3 -m remote_jobs_api.server       # listens on :8321

# Docker
docker build -t remote-jobs-api .
docker run -p 8321:8321 remote-jobs-api

Env vars: PORT (default 8321), RJA_CACHE_TTL (default 300s, how long upstream fetches are cached).
