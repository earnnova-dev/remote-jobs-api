Stop stitching 5 scrapers together

Remotive, RemoteOK, We Work Remotely, Jobicy, and Hacker News each have a different format, a different rate-limit, and a different way to break. Remote Jobs API pulls all five, normalizes every listing into a single schema, dedupes it, and hands you structured JSON or CSV — with an optional 0–100 skill fit-score for ranking.

Built for job boards & aggregator sites, recruiter/ATS tooling, lead-gen and market research, and AI agents that need structured job data in a single call.

Why it's different

One schema, every board

No per-board adapters on your side. A remotive job and a wwr job look identical.

No session scraping

Reads public job-board endpoints only — no browser, no accounts, no fragile login flows.

Self-hostable

Pure Python stdlib, zero dependencies. Run it on a laptop, a $5 VPS, or the included Dockerfile.

Structured salary

Boards that publish pay come back as parsed salary_min/salary_max + currency/period — filter by floor with ?min_salary=, no regex on your side.

Deterministic fit scoring

No hidden LLM, no black box — reproducible ranking you can reason about and unit-test.

Example

curl "https://<your-host>/v1/jobs?skills=python,backend,api&limit=3"
{
  "count": 3,
  "generated_at": 1790433192,
  "jobs": [
    {
      "id": "94516b10164d3c70",
      "title": "Senior Backend Developer (Python)",
      "company": "Proxify AB",
      "url": "https://weworkremotely.com/remote-jobs/proxify-ab-...-10",
      "location": "Anywhere in the World",
      "category": "Back-End Programming",
      "source": "wwr",
      "published": "2026-09-15T09:01:36+00:00",
      "salary_min": 85000,
      "salary_max": 110000,
      "salary_currency": "USD",
      "salary_period": "year",
      "fit_score": 80
    }
  ]
}

Fields shown when the board publishes them — salary_min, salary_max, salary_currency and salary_period are present on listings that carry parsed pay, and null where a board doesn't publish it. Filter on the floor with ?min_salary= (e.g. ?min_salary=100000).

Install

One command — pure Python stdlib, zero dependencies.

pip install remote-jobs-api

Query the feed directly (JSON or CSV, with an optional 0–100 skill fit-score):

remote-jobs-api --skills python,api --limit 5
remote-jobs-api --source wwr --format csv

Or run the HTTP API server on your own host:

remote-jobs-api --serve --port 8321

Or run from source:

git clone https://github.com/earnnova-dev/remote-jobs-api
cd remote-jobs-api
python3 -m remote_jobs_api.server          # listens on :8321

Or with Docker:

docker build -t remote-jobs-api .
docker run -p 8321:8321 remote-jobs-api

Or one command with the included docker-compose.yml (keys persist in a volume): export RJA_ADMIN_TOKEN=*** && docker compose up -d.

Want to know the moment a feed breaks silently? jobfeed-watchdog is a drop-in GitHub Action that fingerprints a feed every 6 hours and fails the build on count collapse, schema change, or outage. Or track new matches with GigWatch.

Env vars: PORT (default 8321) · RJA_CACHE_TTL (default 300 s) — how long to cache upstream fetches.
