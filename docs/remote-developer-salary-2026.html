Data source & methodology: These numbers are a snapshot taken from the Remote Jobs API on Sep 29, 2026. The API aggregates 5 remote job boards (Remotive, RemoteOK, Jobicy, We Work Remotely, Hacker News) into one normalized endpoint. Salary data is taken directly from job postings where the employer publishes it. Percentiles are computed on the midpoint of each listed range. The API itself is live and updates continuously — this page is a point-in-time snapshot of that data as of Sep 29, 2026.

What Remote Means for Your Salary in 2026

The data shows that top-quartile remote engineering roles (P75+) cluster around $210,000+ per year for US-based positions. Senior and staff-level roles command the highest rates, with security and AI engineering leading the top of the range.

EU remote salaries run at roughly 65–75% of US equivalents for comparable roles, with senior EU security and SRE roles reaching the €110k–130k band.

Contract/hourly roles show a wide range ($50–$170/hr) depending on seniority and specialization — senior AI engineers and independent developers command the top rates.
