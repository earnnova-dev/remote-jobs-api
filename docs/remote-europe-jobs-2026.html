Try it — no API key, no signup, one call

The free tier needs no authentication and allows 100 calls per month. Keep only Europe-relevant roles with a single Python call using the standard library — no dependencies:

import json, re, urllib.request

url = "https://remote-jobs-api.tten.no/v1/jobs?limit=500"
with urllib.request.urlopen(url) as r:
    data = json.load(r)

# Keep roles based in or targeting Europe / EMEA
EU = re.compile("Europe|EMEA|EU|Germany|France|Netherlands|Spain|Italy|"
                "Poland|Sweden|Norway|Denmark|Finland|Ireland|Austria|Switzerland", re.I)
for job in data["jobs"]:
    if EU.search(job.get("location", "")):
        sal = job.get("salary") or "n/a"
        print(f"- {job['title']} | {job['company']} | {job['location']} | {sal}")

Useful parameters: source (remotive, remoteok, jobicy, wwr, hn), limit, and min_salary. Combine with your own location match on the location field to keep only the roles you want.
