Why a feed beats a job board for leadership roles

If you’re a director, head-of, VP or C-suite executive — or building a tool for exec search, executive comp research, or a leadership bench — a static job-board page goes stale the moment a listing closes. A feed doesn’t. You can:

  • Pull GET /v1/jobs?limit=500 on a schedule and only surface new leadership roles (dedupe on the stable id).
  • Filter by min_salary to skip roles that won’t meet your target, or by source to bias toward a board you trust.
  • Rank by fit_score to surface the best-matching executive role for a specific mandate.
  • Get salary where the board publishes it — 14 of the 35 leadership roles currently list a concrete figure (40%), e.g. Amplitude up to $476,000; Help Scout $263,000–$290,000; hims & hers $230,000–$280,000.

Try it — no API key, no signup, one call

The free tier needs no authentication and allows 100 calls per month. Grab the current leadership roles with a single request:

curl "https://remote-jobs-api.tten.no/v1/jobs?limit=10"

Or pull it into a script with the Python standard library — no dependencies. The example below narrows to the leadership subset client-side:

import json, urllib.request

url = "https://remote-jobs-api.tten.no/v1/jobs?limit=500"
with urllib.request.urlopen(url) as r:
    data = json.load(r)

LEAD = ("director", "head of", "vice president", "vp of",
        "chief", " cto", "cfo", "coo", "cmo", "ceo")

def is_leadership(job):
    t = (job.get("title") or "").lower()
    return any(k in t for k in LEAD)

for job in [j for j in data["jobs"] if is_leadership(j)][:10]:
    sal = job.get("salary") or "n/a"
    print(f"- {job['title']} | {job['company']} | {job.get('source')} | {sal}")

Useful parameters: skills (comma-separated), source (remotive, remoteok, jobicy, wwr, hn), limit, min_salary, and min_score (minimum fit_score).
