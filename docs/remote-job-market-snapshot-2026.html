Most "remote salary" pages publish a static chart from last year's data and call it done. This page is different: every number below is computed in real time by the Remote Jobs API snapshot endpoint, which pulls live listings from Remotive, RemoteOK, Jobicy, We Work Remotely, and Hacker News, normalizes them into one schema, and aggregates salary, demand, and skills in one call. The figures on this page are a captured sample; the endpoint gives you the current market the moment you query it.

Get this data yourself

One call returns the whole snapshot as JSON — count, salary distribution, demand by source, top skills, and top companies. No scraping, no per-board parsing, no key for the snapshot.

curl https://remote-jobs-api.tten.no/v1/snapshot

Full normalized listings (title, company, salary_min/salary_max, tags, source, fit-score) live at /v1/jobs. Self-host the whole thing — it's stdlib-only Python and MIT licensed — or use the live API.
