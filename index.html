Remote Jobs API

Live, normalized remote-job listings from 5 boards (Remotive, RemoteOK, Jobicy, We Work Remotely, Hacker News) in one endpoint and one schema — with a deterministic 0-100 skill fit-score.

What you get

One schema, every board

No per-board adapters. Every listing is normalized to the same fields: title, company, location, salary, tags, published, source, url.

Skill fit-score

Pass skills=python,backend and every job carries a deterministic 0-100 score. Ranked best-fit-first. No LLM, no black box — reproducible and unit-testable.

JSON or CSV

Swap the format with one query param. Export to spreadsheets or pipe straight into your pipeline.

Built for agents

One call, structured data. Ideal for job boards, recruiter tooling, lead-gen, market research and AI agents.

Try it

curl "https://remote-jobs-api.example.com/v1/jobs?skills=python,backend,api&limit=3"

# Self-host (zero dependencies, pure stdlib):
pip install remote-jobs-api
remote-jobs-api --skills python,backend --limit 3     # CLI
remote-jobs-api --serve --port 8321                  # HTTP API
